# Prototipo-Estufa-Inteligente-Fischertechnik  
O projeto ilustra, de forma prática, como a integração entre sensores e atuadores permite criar soluções automatizadas para o controle das condições ambientais de uma estufa.

## Resumo
Um LED simula a incidência de luz solar, enquanto um fototransistor identifica a luminosidade do ambiente. Quando a luz é detectada, o sistema aciona um motor que abre a cortina, permitindo a entrada do vento para circulação de ar e refrescar o ambiente. Quando a luminosidade deixa de ser identificada, o motor é acionado novamente para fechar a cortina.
